# Team Smandych Muay Thai & Kickboxing — new website

Concept preview of the new homepage for Team Smandych (downtown Calgary), built by Femik.
One goal drives every decision: turn a visit into a booked **free trial class**.

- **Status:** prototype (homepage preview to show the owners)
- **Live preview:** https://kimciddev.github.io/teamsmandych/
- **Brand kit:** https://kimciddev.github.io/teamsmandych/brand-kit/

## What's here

| Path | What |
|---|---|
| `index.html` | Homepage (mobile-first) |
| `assets/css/styles.css` | All styles |
| `assets/js/data.js` | Gym info, classes, weekly schedule, coaches — **edit this to update content** |
| `assets/js/app.js` | Today/week schedule, booking sheet, printable week |
| `assets/img/` | Logo and photos used by the site |
| `brand-kit/` | SVG + PNG logo kit for the client (+ zip) |

## Open locally

Static files only. Open `index.html`, or run `python3 -m http.server` and go to http://localhost:8000.
