**Colours:** black `#0b0b0b` · brand green `#34b25a` · deep green `#0f3d22` · glove red `#c8202f` · silver `#c9ccd1` · white `#ffffff`

**Colour roles on the site:** red = action (book, call) · green = brand and information · silver = secondary text.

Note: the elephant is high-resolution raster artwork (PNG). For large-format print or embroidery, a vector version (SVG/AI) would still be the best source.
